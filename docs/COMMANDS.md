# Commands

## User

### `/start`

Shows basic information about the bot and how to connect it through Telegram Business.

## Admin

The following commands are available only to the configured administrator.

### `/users`

Shows accounts currently connected to the bot.

### `/check`

Enables or disables message monitoring for connected accounts.

### `/monitors`

Shows the current monitoring status and connected accounts.

### `/exclude`

Excludes a user or chat from monitoring.

Example:

`/exclude @username`

### `/include`

Removes a user or chat from the exclusion list.

Example:

`/include @username`
