# FAQ

## What does Telegram Message Tracker do?

It tracks deleted and edited messages received through Telegram Business.

## Can it recover old deleted messages?

No. The bot can only track messages that it received while running.

## Does the bot require Telegram Business?

Yes. Telegram Business integration is required.

## Where are secrets stored?

Secrets such as bot tokens and Redis credentials should be stored in environment variables.

## Does the repository contain private user data?

No private user data should be committed to the repository.
